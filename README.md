# Adulto.OS - Manual de Sobrevivência (ODS 4.4)

## Como executar
1. Extraia o ZIP e abra a pasta no terminal.
2. Instale as dependências:
   npm install
3. Inicie o servidor:
   npm start
4. Abra no navegador exatamente em:
   http://localhost:3000

Nota: Não abra o arquivo index.html clicando duas vezes nele (file://), pois o login precisa do servidor Node rodando em http://localhost:3000.
