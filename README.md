
Desburocratiza — Manual de Sobrevivência Adulta 🐱📄

"A vida adulta não vem com manual. A gente fez um."
O Desburocratiza é uma plataforma educacional interativa e gamificada criada para preencher a lacuna que a escola deixou: você sai do ensino médio sabendo a fórmula de Bhaskara, mas não faz ideia de como ler um holerite, declarar imposto de renda ou evitar juros abusivos no cartão de crédito.
Nossa missão é traduzir a burocracia da vida real sem juridiquês e sem drama, preparando jovens adultos para o mercado de trabalho, finanças pessoais e independência.

🎯 O Problema que Resolvemos

Muitos jovens terminam a escola sem conhecimentos práticos essenciais para o dia a dia. O Desburocratiza transforma temas complexos e intimidadores em jornadas leves, práticas e seguras — onde você pode testar cenários reais sem arriscar seu dinheiro ou seus documentos.

✨ Funcionalidades Principais

• 🧭 Trilhas de Missões: Jornadas guiadas por momentos reais da vida, como Primeiro Emprego, Vou Morar Sozinho e Me Enrolei no Cartão.
• 🧪 Laboratório da Vida Real (Simuladores): Ferramentas práticas para testar situações antes de encarar o mundo real:
	• Holerite Interativo: Entenda para onde vai cada desconto do seu salário.
	• Juros do Cartão: Compare parcelamento, pagamento mínimo e o efeito bola de neve.
	• Imposto de Renda: Quiz guiado para saber quando e como declarar.
	• Contrato de Aluguel: Modo detetive para identificar cláusulas que merecem atenção.
	• Gerador de Currículo: Crie um currículo limpo e otimizado para sistemas de recrutamento (ATS).
• 🎮 Mini Games (Treino Rápido): Desafios curtos para fixar conceitos e ganhar XP, como Verdade ou Cilada?, Detetive do Holerite e Orçamento Relâmpago.
• 📖 Guias de Bolso: Leituras rápidas de 1 minuto direto ao ponto sobre temas urgentes (como abrir conta sem cair em taxas, limpar o nome no SPC ou pedir demissão).
• 🐾 Mascote Guia (Frederico): Um assistente interativo que acompanha e orienta o usuário em toda a jornada de aprendizado.

🌍 Impacto Social (ODS 4 — ONU)

Este projeto está alinhado ao Objetivo de Desenvolvimento Sustentável 4 (Educação de Qualidade) da ONU, especificamente conectado à Meta 4.4: desenvolver habilidades relevantes para emprego, trabalho decente e empreendedorismo.

🚀 Como Rodar o Projeto Localmente

bash
# 1. Clone este repositório
git clone https://github.com/Dexzow/TCC_Project

# 2. Acesse a pasta do projeto
cd desburocratiza

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
Após iniciar, acesse http://localhost:3000 no seu navegador.
